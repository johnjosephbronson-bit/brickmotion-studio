# BrickMotion Studio

Build an app that allows me to animate a lego minifigure from a list of bricklink parts with a clean ui and some jump to poses that i can select and it will automaticly animate the moving from the current pose to the selected one on a timeline while following how lego minifigures move in the lego movie, as well as a poser that allows me to manipulate the way pose of the limbs of the minifigure, and an exporter.
